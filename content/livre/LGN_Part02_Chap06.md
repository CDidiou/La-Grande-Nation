*Extrait du roman publié par Florian de Saint-Euphrasie dans la gazette La Garonne Emancipée — « Le Lion du Fleuve »*

L'hiver approchait.

Le Saint-Laurent se couvrait de brume.

Les Britanniques tenaient les rives.

Les Français tenaient les villages.

Les Canadiens tenaient leur colère.

Balthazar réunit ses capitaines.

Armand était à côté de lui.

Ranga se tenait au fond de la pièce.

La carte était déployée.

— Ils sont plus nombreux, dit Armand.

— Je sais.

— Ils ont davantage de canons.

— Je sais.

— Ils ont davantage de navires.

Balthazar regarda le fleuve.

— Nous avons le brouillard.

Le lendemain, les Français partirent.

Pas de fanfare.

Pas de drapeaux.

Pas de tambours.

Seulement les rames.

Le brouillard couvrait tout.

Les navires avancèrent.

À bord du bâtiment amiral, Balthazar tenait son sabre.

Armand se trouvait derrière lui.

— Tu sais où nous allons ? demanda Armand.

— Non.

— C'est inquiétant.

— Pas du tout.

— Pourquoi ?

Balthazar sourit.

— Eux non plus.

Un canon tonna.

Puis un autre.

Les projectiles frappèrent l'eau.

Une silhouette apparut.

Puis une autre.

Le combat éclata.

Les navires se heurtèrent.

Les hommes sautèrent.

Les cordages brûlèrent.

Le brouillard devint rouge.

Balthazar aperçut soudain le pavillon de Barnardy-Lyle.

Il donna l'ordre d'approcher.

Les deux bâtiments se heurtèrent.

Barnardy-Lyle attendait sur le pont.

Balthazar monta.

Les deux hommes se retrouvèrent face à face.

— Capitaine, dit l'Anglais, êtes-vous réellement convaincu que cette entreprise puisse réussir ?

Balthazar sourit.

— Je ne sais pas si elle réussira.

Il leva son sabre.

— Mais elle aura le mérite de vous coûter cher.

Ils se battirent.

Le duel dura quelques instants.

Puis une explosion secoua le navire.

Le brouillard les sépara.

Lorsque la fumée se dissipa, Barnardy-Lyle avait disparu.

Le combat continua.

Puis les Britanniques commencèrent à reculer.

Les Canadiens poussèrent un cri.

Les Français hissèrent leurs couleurs.

Armand monta sur le pont.

— Nous avons gagné.

Balthazar regarda le fleuve.

— Oui.

Il semblait presque déçu.

— Et maintenant ?

Balthazar sourit.

— Maintenant, nous allons gagner encore.
